## Scope and product safeguards

The general application-plugin host and plugin-settings section were already excluded, but inherited **Appearance** still offered a visible **Browse themes** button, a **More themes** catalog, plugin-provided theme choices, and an installation/trust prompt. Those controls used retired `plugins.*` IPC/marketplace services. Main also retained an `orca://plugins/...` pending-install-link state, macOS desktop handoff entry, IPC consume handler, preload callback and renderer subscription, even though the destination Plugins Settings page no longer exists.

This milestone removes the **installed app-plugin theme and marketplace UI affordances**, drops the Settings-level plugin trust-dialog host, and detaches the **plugin-link routing pipeline** across Main, preload, web preload and renderer. The obsolete `PluginInstallLinkState` is removed; its existing test file is retained and converted to negative guards, rather than recording a new upstream file deletion. The macOS handoff still transfers **skill-share links and Open With documents**; Settings/quit and unrelated UI IPC remain.

**Retained:** built-in **System / Dark / Light** application modes, per-mode **Built-in / Match Terminal** app color slots, **Same as app / built-in Light / built-in Dark** Monaco settings, regular Appearance and terminal settings, local browser/Chromium extensions, provider-native skills/MCP, Git and local runtime/PTY. Previously saved plugin-specific theme IDs display built-in/follow-app fallbacks **without a write on mount**; they are only replaced following an explicit user selection. Neither user preferences nor unrelated credentials were silently migrated.

**Not covered:** the obsolete `plugins` enum member in shared Settings navigation/deep-link helpers; unmounted app-plugin preview/update-toast stores, general plugin-host preload namespace and dormant worker/manifest code, and other appearance plugin icon/terminal-theme adapters still need consumer-traced cleanup. This milestone is **not** a total EX-03/EX-10 closure.
