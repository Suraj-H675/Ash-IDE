## Active importer trace and change

After detaching the general application-plugin service, Main IPC, market, panels, editor and screenshot systems, the **live keyboard** still loaded plugin command contributions to intercept application shortcuts and native-chat toggle precedence. The built-in dispatcher and Main-to-renderer sidebar/workspace menu bridges still called `runBuiltInOrReplacement` for actions, which could wait for an app-plugin worker and replace the normal operation. That host is excluded in Ash. The retained browser/terminal/native-chat and native shortcut ownership policies are **not** plugin features.

**Changed live paths:** `use-global-keybindings.ts` no longer subscribes to plugin commands, allows plugin chord interception or delays search/floating workspace actions behind replacement workers. `app-command-handlers.ts` executes the retained action directly after the same existing ownership, authority and terminal-capture checks. `use-native-chat-toggle-shortcut.ts` no longer gives general-plugin chords precedence, but keeps recent-tab-switcher precedence, focused-workspace ownership, transcript/readability and real agent eligibility. Both `settings-sidebar-ipc-bridge.ts` and `workspace-shortcut-ipc-bridge.ts` invoke their existing built-in sidebar, worktree-history, task and board handlers directly. Built-in alias action IDs, settings shortcut recorder, stored remapping, modal suppression, text-input composition guards and terminal/floating target routing were retained.

**Separated:** `globalShortcutTargetYields` and its unchanged legitimate text input/floating terminal/panel target logic into new plugin-independent `src/renderer/src/lib/global-shortcut-target-yields.ts`. The old plugin command definitions module remains for the separately traced Settings/command-palette legacy consumers but no longer supplies that ownership policy to active shortcuts. **Removed:** `src/renderer/src/lib/plugin-command-replacements.ts` (87 lines), recording original pinned SHA-256 `280591258321dcfe8d186ab8d7d11f9ee9774038e6c33ee489756f122f2fcabf` in `docs/provenance/ash-exclusions.json`. Its existing obsolete fallback test was narrowed to the retained explicit no-app-plugin-API error; no synthetic replacement worker kept alive only for tests.

No real user repositories, browser profiles, credentials, providers or external application data were modified.
