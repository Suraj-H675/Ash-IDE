## Reviewed import graph and changes

Previous M8 milestones detached the general IDE application-plugin service from startup, removed its renderer Settings/marketplace, retired worker-hook interception and removed its desktop/web preload namespace. The Main IPC root `src/main/ipc/plugins.ts` and its five registrar children still contained installers, approvals, enablement, custom-editor frames, marketplace discovery/installation, panel pushes, per-plugin settings and plugin-contributed status-bar IPC. A trace of **all source imports and registration calls** found no Main startup importer: the only remaining non-group dependency was an unused Orca plugin-uninstall test fixture.

Deleted exactly **seven inherited Orca files**: `src/main/ipc/plugins.ts`, `plugin-frame-entry-ipc.ts`, `plugin-marketplaces.ts`, `plugin-panel-push-ipc.ts`, `plugin-settings-ipc.ts`, `plugin-status-bar-ipc.ts`, and `src/main/plugins/__mocks__/plugin-uninstall-log-test-fixture.ts`. Each original upstream source SHA-256 and an M8-specific exclusion reason is in `docs/provenance/ash-exclusions.json`. An existing M8 guard was updated to check for absence of the now-deleted IPC root.

Added a **packaged-Main IPC exclusion gate** to `verify-ash-packaged-asar-hygiene.cjs`: inspect the compiled `out/main/index.js` inside ASAR **and** any unpacked counterpart for the reviewed application-plugin installer, worker command, status-bar, custom-frame and marketplace channel names. This is precise enough to avoid rejecting unrelated minified text with a `plugins:` substring. The previous packaged-preload `plugins:*` gate remains. **The new gate is build-artifact enforcement; it does not purport to delete arbitrary plugin-related source that is not in the Main entrypoint.**

**Preserved:** original-folder-first workspaces, Git, PTY/process persistence, native chat, normal filesystem/editor saves, Chromium browser **extensions**, provider-native hooks/skills/MCP and permissions, settings and existing runtime/CLI IPC registrations. No real user repository, provider account, browser profile, other app installation, secrets or upstream checkout was changed.
