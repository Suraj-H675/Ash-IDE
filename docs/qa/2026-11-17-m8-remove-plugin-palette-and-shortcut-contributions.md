## Bounded importer trace and implementation

Following earlier M8 exclusion of app-plugin keyboard worker interception, three **active UI** sources still accepted general app-plugin contributions despite their excluded host/preload: Cmd+J command palette action and new-file entries, Shortcut Settings' dynamic plugin shortcut definitions and conflict priority, and New Tab's plugin-created document entries. Source import tracing verified that `components/cmd-j/plugin-quick-actions.ts` was consumed only by the palette; `lib/plugin-command-keybindings.ts` was consumed only by Shortcut Settings and was already detached from runtime keybinding ownership.

**Retired:** `usePluginCommands` and `usePluginNewFiles` subscriptions from palette store state, plugin action injectors from the palette project target builder, editable plugin commands and dynamic plugin definitions from Shortcut Settings, and plugin new-file menu item generation from the standard tab creation menu. Removed the no-longer-needed `groupId` prop from the tab creation menu and its caller. Deleted the two orphan general-plugin contribution files, recording original Orca SHA-256 **`2d8a5177ab29fb4b5094809e122555bebc64108f075368ba0eb64dbd9231ea71`** and **`cb331f1e434951c587ae5b1a458804563bb52d97d015dbdde9165d3cb1411187`** with individual exclusion reasons in `docs/provenance/ash-exclusions.json`.

**Preserved:** the built-in Cmd+J action catalog, including New Terminal, Markdown and browser; its ranked search and settings/project results; native shortcut definitions and customized binding overrides; keyboard conflict detection for built-in actions, macOS Mission Control warnings, disabled-agent launch visibility, and terminal shortcut policy; standard New Terminal, New Browser Tab, New Markdown and Open Markdown menu entries. Palette action results are re-evaluated on render rather than relying on legacy plugin-array changes, so current localized labels remain available. No real user repositories, account credentials, settings files, other application's data or browser profiles were modified.
