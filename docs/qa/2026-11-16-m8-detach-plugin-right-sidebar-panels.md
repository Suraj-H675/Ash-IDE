## Import analysis and implementation

Even after excluding the general app-plugin host, its Main IPC registration, editor takeover and plugin screenshot system, the live Ash right sidebar still imported the app-plugin panel registry, created sidebar activity entries for installed plugin panels, reconciled their status and saved routes, and could lazily mount `PluginPanel` guest frames. Valid legacy `plugin:<publisher>.<id>/<panelId>` keys were also retained across both Main persistence normalization and renderer route hydration.

**Detached:** application-plugin registry, panel health and panel icon contributions from `useRightSidebarActivityItems`; plugin list/fetch status and installed-route reconciliation from `useRightSidebarTabRouting`; lazy `PluginPanel` guest mount and screenshot-only `data-plugin-panel-surface` attribute from the sidebar panel content; plugin-specific props from the sidebar shell; and open-ended plugin tab acceptance from both renderer `normalizeRightSidebarRoute` and Main `normalizeRightSidebarTab`. A hydrated obsolete plugin tab now selects **Explorer**, and the sidebar routing hook also clears that obsolete selection from current local UI state rather than waiting for a nonexistent plugin inventory. The old Search-tab migration still selects Explorer/Search correctly.

**Deleted:** two closed orphan helpers, `plugin-panel-activity-items.ts` and `use-installed-plugin-route-reconciliation.ts`, each with its exact original Orca source SHA-256 and an M8 exclusion reason in `docs/provenance/ash-exclusions.json`.

**Preserved:** normal Explorer, Agents, attached worktrees, PR Checks, Source Control, Checks and Ports sidebar sections, folder-vs-Git visibility, saved folder tab memory, per-panel height/width and resizing, CLI, terminal runtime, real browser and extensions, provider-native hooks/skills/MCP and independent Git state. The UI still permits the separately approved Ports panel where applicable; this milestone is **not** approval of the excluded remote SSH-managed development subsystem. No actual user repository, provider credential, browser profile or external app data was modified.
