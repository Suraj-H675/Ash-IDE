# M8 EX-08 / PK-08 — unship executable speech workers from desktop and local orcad

**Date:** 2026-11-15 (Asia/Kolkata). **Baseline:** canonical `main` `592b73c2d2ba3f938923ed8baafa0c70afefcef0`, clean/synced; [GitHub Actions 43716193672](https://github.com/Suraj-H675/Ash-IDE/actions/runs/43716193672) confirmed **success**. **Feature branch:** `fix/m8-exclude-speech-workers` in the existing isolated worktree `/home/suraj/.devspace/worktrees/Ash-IDE-020c66c5`. **Upstream provenance:** separate read-only Orca pin `55697aec91390357540103f49991458f756b41cc`; original MIT retained.

## Why this slice was required

The approved specification excludes app-managed voice/dictation (EX-08) and executable speech/native model payloads in distribution (PK-08). The preceding milestone removed 17 speech/general-plugin **CLI** entrypoints and refused ambient `ORCA_SPEECH_RECOGNIZER_DIR` in the retained `serve` launcher, but inspection of its **actual shipping AppImage** showed `/out/main/stt-worker.js` still inside `app.asar`. The separately built local orcad server also listed `stt-worker.js` as a required child artifact, and `installOrcadHostAdapters()` still injected the legacy `orcadSpeechServiceFactories`. This was not a safe EX-08 closure. Native browser extensions, provider-native agents/hooks, persistent PTY and local orcad are **retained** and must not be removed as a shortcut.

## Implemented boundaries

1. Removed the standalone STT child entry from `ORCAD_CHILD_ENTRY_POINTS` and the required `ORCAD_ARTIFACTS` manifest. Fresh builds reset the owned output directory, so a stale worker cannot survive a template regeneration through this path. The orcad template's strict file-inventory verifier rejects an unexpected `stt-worker.js` or native speech add-on.
2. `installOrcadHostAdapters()` now explicitly resets speech factories to `null`, rather than installing the inherited speech service implementation. If a previous component or test has installed a factory, a new Ash orcad initialization revokes it. A focused test injects a synthetic factory, invokes actual adapter initialization, and observes that model-service calls reject with `speech_unavailable`, without attempting a real model download or provider access.
3. The desktop packaging config excludes the exact compiled `out/main/stt-worker.js`. The shared `afterPack` ASAR verifier now fails closed for this worker in either packed/unpacked form, and for `sherpa-onnx*` native speech dependencies inside the archive or native dependency copy directories. It runs on every platform's package output, not just Linux. The source worker remains available in the checkout for later vertical retirement; it is no longer an executable shipping artifact.
4. Added synthetic **red-first** test cases for both manifest and packaged ASAR inclusion. Before the implementation the two suites returned **7 expected failures**; after the correction the same suites returned **46/46 PASS**. The new `ash-excluded-speech-service.test.ts` completes **47/47 PASS** in the combined suite. Foundation CI now includes the orcad inventory test and live factory-revocation test alongside the existing ASAR checks.
