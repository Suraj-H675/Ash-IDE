## Entry-point review and changes

The prior M8 work removed the app-plugin manager and theme marketplace, but **EditorEditFileSurface** still mounted an app-plugin catalog suggestion banner for binary/unrecognized and ordinary text files, plus a legacy Orca plugin-frame fallback notice. Its **View plugin** control navigated to the already-removed Settings Plugins page. An application-wide renderer lifecycle additionally registered `registerPluginViewIpcBridge` for excluded `orca plugin open` / `shot` view requests, and preload still exported the corresponding plugin view-request/reply handlers. Settings navigation also still accepted `pane: 'plugins'` as a valid externally hydrated deep link and allocated special layout width to that removed page.

Removed the editor's **marketplace suggestion and plugin fallback notice mounts**, the application-lifetime plugin-view listener, the two view-request/reply methods from the existing plugin preload API and runtime bridge, and the removed Settings pane's special width. Externally validated Settings deep links now reject `plugins`. To avoid corrupting unmounted historical Orca consumers before their separate cleanup, the legacy `SettingsNavTarget` TypeScript union still includes `plugins`, but `isSettingsNavigationTarget` expressly refuses it at runtime.

Deleted the original `PluginFileTypeSuggestion.tsx` (123 lines) and `plugin-view-ipc-bridge.ts` (23 lines), whose final active importers were removed, and recorded each exact original source SHA-256 with an explicit M8 exclusion reason in `docs/provenance/ash-exclusions.json`. The pinned upstream checkout and source ledger are unchanged.

**Retained:** ordinary file-open and unsupported-binary fallback, image/media, text Monaco, Markdown/CSV/notebook viewer paths, terminal/browser IPC and all normal Settings destinations. The general plugin preload namespace, dormant plugin preview/worker/custom-editor code, and plugin-provided syntax/editor adapters are **not yet fully excluded**; no claim is made that every app-plugin implementation is removed from main/renderer bundles.
