## Inspectable implementation

`qa:release:appimage-embedded-identity` invokes `config/scripts/desktop-distribution/release/verify-ash-appimage-embedded-identity-qa.mjs`, assisted by dedicated source modules for pinned file handling, bounded reader invocation, SquashFS structure/listing, and payload identity. The command requires caller-supplied absolute artifact/reader paths, an expected lowercase outer SHA-256, and explicit x64/arm64 architecture. It refuses aliases, nonregular or multiply linked input files, corrupt hashes/architectures, ambiguous SquashFS superblocks, unsafe paths, symlinked required ancestors/files, missing metadata, invalid size limits and mismatched package claims. It snapshots the pinned artifact privately and hashes it before and after parsing. Only four bounded regular files are read from the embedded filesystem; no untrusted AppImage binary is executed or mounted.

The independently installed local **QA-only** reader is `unsquashfs` from the official Arch Linux `squashfs-tools` **4.7.5-1** package (GPL-2.0-or-later). Arch sync database package SHA-256 `ebb145471e5a1c47b5bc49bbc21f83c6ab6ee61940ab5aeb5fea51d936407c9b` was matched and the detached signature verified successfully with trusted Arch key `0429897DE5F3BDAC537A30696D42BDD116E0068F`. Extracted binary SHA-256 `461e1fd9eac39c12e673042807459985636030d5557319343fc3a6ed4ba1677c`. This executable is used only from a private host location and is **not included in Ash Git, the application package, or a managed installer**. No global package installation was performed.

## Residual security and production blockers

The trusted GPL read-only extractor parses untrusted compressed filesystem data under the current user's UID. Hash pinning, timeouts, bounded memory/output and private paths reduce exposure, but **no OS-level sandbox contains a potential native parser compromise**, and a same-UID reader hash-to-exec pathname swap is a residual defense-in-depth risk. This QA-only command is not a production release verifier, is not connected to updater IPC, and cannot authorize switching a running AppImage. Full production requires a signed Ash source/feed policy, complete durable authenticated payload identity, race-resistant maintenance/agent-write admission, real version migration, compatible-state rollback and native package verification.

No merge, push, CI or release is claimed. Native X11/Wayland lifecycle proof, complete installer integration, and real-version rollback remain untested for this QA addition.
