## Change and safeguards

Removed eight excluded groups from **both the imports and registrations** of `src/main/runtime/rpc/methods/index.ts`: `SSH_METHODS`, `MANAGED_SERVER_METHODS`, `SPEECH_METHODS`, `PLUGIN_METHODS`, `PLUGIN_VIEW_METHODS`, `PLUGIN_DEV_EMIT_METHODS`, `PLUGIN_DEV_REQUEST_METHODS`, and `SKILL_METHODS`. Every removed group exclusively declares names under a prefix already forbidden by the authenticated `ASH_RPC_METHODS` filter: `ssh.`, `managedServer.`, `speech.`, `plugins.`, or `skills.`. Removing their eager imports narrows the desktop's production RPC import graph; it does not weaken the existing filter.

An additional `ash-runtime-methods.test.ts` regression checks the defining modules' complete declared method sets against **both** full and Ash registries, forbids source imports/spreads for all eight groups, and positively checks retained browser-tab, manual orchestration, terminal and Git methods. Underlying source modules and older compatibility data remain for separate dependency-reviewed removal. Normal shell/Git-over-SSH is not the removed Ash-managed SSH host administration. Chromium extensions and provider-native skill/MCP/configuration are likewise separate from the removed general app-plugin and centralized skill management APIs. Desktop plugin-view glue still has independent imports; this change does **not** claim complete plugin infrastructure retirement.

## Explicit limits

This narrows production RPC registration but **does not close** the full EX-02, EX-03, EX-05, EX-08 or PK-08 product exclusion gates. App plugin UI/runtime paths, generated RPC schemas, standalone compatibility assets, other legacy RPC groups and unobserved side effects still need their own removal/negative package checks. Browser extensions, native agent integrations, normal Git-over-SSH and real authenticated provider sessions remain separate acceptance cases; neither normal Git-over-SSH network reachability nor real provider credentials were exercised here. macOS/Windows, updater rollback, DEB/RPM and full visual parity were not retested. No existing user projects or provider accounts were changed.
